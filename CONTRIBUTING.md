# Guide de Contribution

Merci de l'intérêt que vous portez à ce projet ! Vos contributions sont les bienvenues et appréciées. Voici quelques directives pour vous aider à démarrer.

## Comment Contribuer

### Signaler un Bug

- Vérifiez d'abord que le bug n'a pas déjà été signalé dans les [issues existantes](https://github.com/RonanDavalan/suivi_des_ip_bannies_avec_fail2ban/issues).
- Si le bug est nouveau, ouvrez une issue et fournissez autant de détails que possible.
- Incluez des étapes pour reproduire le bug, si possible.

### Proposer une Amélioration

- Consultez les [issues existantes](https://github.com/RonanDavalan/suivi_des_ip_bannies_avec_fail2ban/issues) pour voir si votre idée a déjà été discutée.
- Si ce n'est pas le cas, ouvrez une nouvelle issue pour discuter de votre proposition.

### Soumettre une Pull Request

1. **Forkez** le dépôt et clonez votre fork localement.
2. Créez une nouvelle branche pour votre contribution : `git checkout -b ma-nouvelle-fonctionnalite`.
3. Faites vos modifications et assurez-vous que le code fonctionne correctement.
4. Commitez vos changements : `git commit -m "Ajout de ma nouvelle fonctionnalité"`.
5. Poussez votre branche : `git push origin ma-nouvelle-fonctionnalite`.
6. Ouvrez une pull request sur le dépôt d'origine.

### Style de Code

- Assurez-vous que votre code respecte le style de codage du projet.
- Utilisez des commentaires pour expliquer les parties complexes de votre code.
- Vérifiez que votre code ne génère pas de nouveaux avertissements ou erreurs.
